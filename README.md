## What I do

- 복잡한 사용자 흐름을 이해하기 쉬운 화면과 상태 구조로 정리합니다.
- 지도, 실시간 통신, 인증처럼 외부 시스템 의존성이 큰 기능을 안정적으로 연결합니다.
- 배포 이후의 문제를 발견할 수 있도록 모니터링과 성능 검증 환경을 함께 구축합니다.
- 팀이 같은 기준으로 개발할 수 있도록 디자인 시스템, 컨벤션, 문서화를 정비합니다.

`React Native` `Expo` `TypeScript` `Apollo Client` `GraphQL` `Supabase` `Express` `Sentry` `GCP`
